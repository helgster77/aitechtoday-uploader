Privacy policy

This policy covers AI & Tech Today Uploader ("the client"), an internal tool that uploads videos to the AI & Tech Today YouTube channel.

YouTube API Services

The client uses YouTube API Services. By using it you are also subject to the Google Privacy Policy, which describes how Google handles data: https://policies.google.com/privacy.

Information accessed, collected and used

The client asks for one Google permission, youtube.upload. It uses it only to upload videos, with their titles, descriptions, tags, thumbnails and settings, to the channel owner's own YouTube channel. It does not read, collect or store any data about viewers, other channels or other Google accounts, and it uses no cookies or analytics.

Information stored

The only data stored is the OAuth access and refresh token for the channel owner's own Google account, kept in a file readable only by the owner on the owner's computer, so scheduled uploads can run. The client also keeps a local record of each upload it makes (video ID and link).

Sharing

No data is sold, shared or disclosed to third parties. Data is sent only to Google, through YouTube API Services, to perform the uploads.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Once access is revoked, or on request, the stored token is deleted from the owner's computer within 7 days; deleting the token file removes all stored authorisation data. The client stores no other data obtained from YouTube API Services, so nothing else needs to be deleted. Uploaded videos stay on YouTube and can be deleted in YouTube Studio.

Changes

Changes to this policy are published on this page with a new date.
