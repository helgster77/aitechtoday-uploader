Privacy policy

This policy covers AI & Tech Today Uploader, an internal tool that uploads videos to the AI & Tech Today YouTube channel through YouTube API Services.

What the tool accesses

The tool asks for one Google permission, youtube.upload, which lets it upload videos and set their thumbnails on the authorised channel. It does not read, collect or store data about viewers, other channels or other Google accounts.

What is stored

The only data stored is the OAuth token for the channel owner's own account, kept on the owner's computer so uploads can run on a schedule. It is never shared with anyone or sent anywhere except Google.

Sharing

No data is sold, shared or disclosed to third parties.

Revoking access

Access can be revoked at any time from the Google security settings page; the stored token can then be deleted.

Google

The tool uses YouTube API Services. See the Google Privacy Policy.

Contact

To ask about this policy, open an issue on GitHub.
